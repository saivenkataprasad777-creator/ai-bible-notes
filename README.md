# AI Bible Notes

Premium AI-powered Bible reading, study, notes, and sermon assistant.

## Vision

AI Bible Notes combines Bible reading, advanced digital notes, AI Bible study, and AI-assisted sermon capture in one elegant application.

## Brand

- Name: AI Bible Notes
- Logo concept: Open Bible + Feather Pen
- Primary theme: Black + Gold
- Style: Premium, elegant, calm, modern

## Current milestone

**v0.1 — Project Foundation**

The current milestone contains the Flutter application shell, premium theme, animated splash screen, home dashboard, and placeholder modules for Bible, Notes, AI Assistant, and Settings.

## Development

This repository is intentionally being built incrementally. Firebase, Bible content providers, rich notes, handwriting, AI services, sermon transcription, synchronization, and production release configuration will be added in later milestones.

## Important licensing note

Bible translations are not automatically free to redistribute. The production app must use Bible content from an appropriate licensed, public-domain, or otherwise authorized source.
